# 穴居蛛

## 角色定位

幽晶洞窟（`cave`）的普通怪潮主力，稳定代码类型 `crawler`。八条浅色节肢、紫色背纹和青蓝眼点区分于碎石装饰。

## 详细属性与成长

`C=1.2^floor((N-1)/5)` 为关卡循环生命倍率，洞窟分别出现在第 5、10、…、100 关。下表生命参考值均以 `C=1`（第 5 关）为口径；后续循环还需乘以 `C`。循环不增加速度、伤害或掉落收益。详见 [百关循环机制](机制_百关循环.md)。

`t` 为出生时游戏秒；`H` 为首页生命倍率（默认 1，范围 0.5–2）。生命和速度在出生时确定。

| 属性 | 当前代码 |
| --- | --- |
| 生命 | `40 × C × (1 + t/220) × H`；H=1 时 t=0 为 40，t=60 约 50.91，t=120 约 61.82 |
| 移速 | `55 + t × 0.11` 世界像素/游戏秒 |
| 接触伤害 | 11 生命/游戏秒，按持续接触时间结算 |
| 碰撞半径 | 10.8 世界像素 |
| 击杀收益 | 种子计数 +2；1 枚价值 2 的经验点 |
| 生成占比 | 前 20 秒 76%；超过 20 秒 48%，不含首领 |

## 实际技能规则

直接朝玩家移动，没有横向摆动项。八条腿与獠牙是动作表现；没有蛛网减速、毒液、跃扑或召唤能力。接触判定使用圆形半径，腿部伸展不扩大伤害范围。

## 动作与命中表现

- 身体始终朝玩家；两侧各四条腿以交错正弦相位迈步。
- 移动相位每游戏秒增加 5；三种外观变体只有配色差异。
- 模型绘制倍率为 0.6；半径 10.8 为实际世界碰撞尺寸。
- 命中后初始闪白 0.1 秒，显示共享伤害数字、粒子与受损血条，没有独立受击硬直。

## 应对建议

利用其直线追踪聚拢怪群，用贯穿武器和脉冲清理。地面矿轨不会改变怪物路线；避开怪群接触即可，无需躲避未实现的毒液。

## 素材路径及来源

`frontend/src/core-breach-game.html` 的 `drawCaveSpider`，本项目原创 Canvas 路径，使用 `CAVE_PALETTE`。共享击杀掉落规则：磁铁、血包各 5% 判定，分别受 20 游戏秒冷却限制。相关布局见 [地图_幽晶洞窟.md](地图_幽晶洞窟.md)。
