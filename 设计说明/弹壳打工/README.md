幽月回刃已接入**新升级玩法**：幽刃齐发、幽月刻印、血玉蓄锋与超武幽月断界。幽刃齐发每级抛掷数量+1（初始1把，三级后4把）；主线为去程留印、走位拉回刃、返程收割与接刃终斩，采用固定觉醒配方；详见[武器文档第五节](幽月回刃.md)。当前专属候选池已替换旧规则，三个分支全满后提供三张通用强化。

零域脉冲炮已接入**相同增量升级与天降极光**：磁场扩容每级半径＋16（64→80→96→112），裂核追击每级微核＋1（0→1→2→3），电浆残域每级每秒＋12%D（固定2.5秒）。三条各Ⅱ后下次升级赠送“零域·磁极坍缩”，每10秒独立锁定地面落点，半径5细束天降0.3秒，再用1秒扩成半径30的笔直蓝白光柱，两侧黄色辉光，60%不透明度，600%D必暴并可判定额外暴击，光束1秒淡出；地面坍缩整体不透明度40%，为普通聚能黑洞的1.5倍半径，3秒内100%D／秒、减速60%且不聚怪；不通过炮口发射或替换普通核心。普通主场可将所有怪物中心锁定，微核命中后保留28px／0.45秒小磁场。详见[完整规则](零域脉冲炮.md#二战斗机制与循环流程)。

## 四、视口与布局规范（严格竖屏）

升级选卡弹层与游戏界面同宽并居中，所有升级卡片宽度占游戏界面（`#game`）的 **2/3**，手机和桌面同步适配。详见 [升级界面规则](总体玩法.md)。

- **游戏显示模式**：**全平台严格竖屏（Portrait）**，手机端全宽居中，桌面端居中保持手机竖屏比例（最大宽度 $500\text{px}$），不采用任何横向分栏。
- **准备页（首页）**：手机页面全屏垂直流式布局，展示关卡/武器/角色轮播选配卡片。“开始打工”下方紧接同宽灰色“结束打工”按钮，点击返回工具首页。
- **首页文案**：标题只显示纯数字编号与关卡名称，例如“6 荧光温室”；不显示副标题、切换说明、关卡输入框、循环倍率说明、武器/角色选择标签、武器属性摘要及角色介绍。
- **武器卡片素材**：使用 `frontend/素材库/弹壳打工/weapons/` 中素材，青玉剑、幽月回刃和零域脉冲炮为透明 PNG，太刀与AK47为 SVG；幽月回刃使用 `dart-black-red-edge-selected.png` 黑色刀面、连续绯红刀锋与八颗红宝石，同时复用于手持和弹体；零域脉冲炮使用`blaster-tech-low-profile.png`低矮内嵌扳机与前端齐平版炮体，统一复用于升级卡、装备栏和手持。武器在箭头之间等比例居中显示，左右箭头使用镜像SVG，点击区域44×44px。
- **关卡切换箭头**：放在关卡图片外侧的左右两边，垂直居中；只绘制箭头，没有背景、边框或阴影，保留至少 44px 的点击区域。
- **关卡卡片大小**：相较原 280px 封面布局，图片两侧的页面留白各缩小至原来一半，卡片按剩余宽度等比例放大；箭头位于左右剩余留白的中心。
- **战斗状态面板**：暂停按钮、等级、计时、种子计数、血条与经验条位于战场上方的独立信息框，沿用关卡信息框的背景、边框、圆角和宽度；依次排列为关卡信息框、战斗状态框、战场和装备框，间距 8px。小地图留在战场右上角（48×48 CSS 像素，上边距 10px、右边距 12px）。音效开关位于暂停菜单。
- **暂停菜单**：按钮依次为“继续打工”“音效开关”“全屏”“结束本班”“返回游戏首页”。“结束本班”使用与全屏、返回首页一致的带边框按钮，位于倒数第二位。
- **局内战斗视口**：中央区域为正方形战场核心视口，尺寸为 **$500\text{px} \times 500\text{px}$**（以手机屏幕宽度为准，最大不超过 $500\text{px} \times 500\text{px}$）。
- **战场实际世界尺寸**：$1000\text{px} \times 1000\text{px}$（四面设有能量围墙，镜头以角色为中心平滑移动）。
- **外部黑屏区域信息布局（紧贴主战场视口）**：
  - **紧邻主战场上方**：依次展示**关卡信息框**（关卡编号、关卡名称、所属区域、通关目标倒计时、波次进度条、当前波次详情、怪物血量难度倍率、当前击杀数）和**战斗状态框**（暂停、等级、计时、种子、生命与经验）。
  - **紧邻主战场下方**：展示**装备与攻击属性信息**（当前武器图标与名称、定位标签、出战角色与职业说明、超武突破状态提示、6格实时攻击属性矩阵【伤害、攻速、范围、弹道/剑柄数、穿透/打击次数、暴击率与暴击伤害】、已选强化芯片列表）。
  - **紧凑布局原则**：信息栏与 $500\text{px} \times 500\text{px}$ 主战场视口紧凑贴合（间距 $8\text{px}$），并在屏幕中央整体垂直居中，**不固定于手机或屏幕的最顶部和最底部两端**，余量黑屏留置于最外围。

## 五、局内掉落道具机制（Items & Pickups）

击杀怪物除了掉落种子/经验点（普通怪掉落 1 枚、精英怪掉落 12 枚）之外，还设有独立判定的**战场消耗道具掉落系统**：

| 道具标识 | 道具中文名 | 掉落概率 | 内置冷却（CD） | 拾取生效规则与数值口径 | 外观与视效表现 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `magnet` | **磁铁** | **5%** | **20.0 秒** | 角色碰撞拾取后，**立即吸附并捡取全地图所有现存经验点**。所有经验宝石获得吸附标记，以 $420 \sim 600\text{px/s}$ 超高速直奔玩家并逐个结算升阶 | 悬浮马蹄形双极磁铁（红/蓝双色与白银磁极），伴随金色脉冲能量光环与周围电弧微粒；拾取迸发金色冲击波与 `🧲 全图吸附!` 提示浮字 |
| `medkit` | **血包** | **5%** | **20.0 秒** | 角色碰撞拾取后，**恢复角色最大生命值的 10%**（**严格向上取整**：`Math.ceil(maxHp * 0.1)`），生命值上限封顶 | 悬浮战地医疗箱（圆角手提箱与醒目红十字），伴随翠绿生机光环波动；拾取迸发翡翠治愈涟漪并浮现 `+X HP` 绿色治愈数值 |

### 道具通用运作规则
1. **内置独立冷却**：磁铁与血包各自维护独立的 **20 秒掉落冷却计时**（`magnetDropCd` / `medkitDropCd`）。道具掉落瞬间开始倒计时 20 秒，冷却期间击杀怪物不会再次掉落同类道具。
2. **永久驻留与多件累积**：掉落后**不会因为超时而消失**，未拾取时永久留在地图上；全图可以**同时累积存在多个**血包与磁铁。
3. **触碰拾取防护**：掉落道具独立于角色的“采集引力”吸附圈（防止未受伤或低经验时意外误吸浪费），必须角色本体靠近（碰撞判定距离 $\le 28\text{px}$）主动踏过拾取。
4. **小地图雷达专属标记**：当战场上出现掉落道具（磁铁或血包）时，右上角小地图（雷达）上会自动标注醒目的金色**小五角星标记**（伴随微光呼吸律动），拾取后自动消除。

## 通用强化与主动技能（2026-10-15）

- 普通卡池精简为四类：巡游步伐（移速＋18%）、聚能校准（伤害＋30%）、会心一击（暴击率＋10%、暴击伤害＋25%）、神经超频（实际攻速＋16%）；全部用百分比显示，暴击两项按百分点相加，接近上限显示真实增量。规则见[总体玩法](总体玩法.md#1-通用芯片池4种)。
