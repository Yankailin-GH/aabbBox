# 主动技能 · 时间停止

> 当前已实现。关联：[总体玩法](总体玩法.md)、[目录](README.md)。

| 项目 | 当前规则 |
| --- | --- |
| 定位 | 全角色、全武器共用的脱困控制技能 |
| 操作 | 右下按钮或空格；开局就绪，冷却中及暂停、选卡、结算时不能重复施放 |
| 冷却 | 60模拟秒，从施放时开始计算；无升级减免 |
| 效果 | 全地图全部普通怪、精英、首领静止2模拟秒，停止自主移动、转向、动作与接触伤害 |
| 新生敌人 | 刷怪不暂停，新刷出的敌人也受剩余时长影响 |
| 玩家与世界 | 玩家可移动、自动攻击、拾取；弹体、普通磁场／微核／超武／持续伤害、刷怪和关卡计时照常 |
| 磁场交互 | 时停期间不能把怪物拉向中心；磁场计时、爆炸与伤害仍继续，不能延长磁场生命 |
| 伤害 | 时停本身不造成伤害，无旧脉冲范围或清屏伤害 |
| 时间口径 | 暂停及选卡时主循环不推进，剩余时长和冷却保持；单帧跨过2秒边界，仅恢复边界之后的移动时间 |
| 清理 | 结算清理时停，重新开局清理时停与冷却；结束不补发效果 |
| 视觉 | 冰蓝秒表＋暂停符号图标；全场轻蓝罩层、怪物静止圆环与暂停标记，顶部显示剩余秒数，按钮显示冷却 |
| 素材 | `frontend/素材库/弹壳打工/icons/skill-time-stop.svg`，128×128，viewBox 64×64，透明背景，项目原创手写SVG；动态覆盖层由Canvas绘制 |
| 成长 | 当前无专属升级路线、范围强化或超武；普通卡不再提供广域脉冲 |

使用建议：被围住、需要穿过怪群或等待下一次主爆时释放。普通磁场在时停期间仍会结束，不应将时停当作延长聚怪时间的升级。

验证：通用与时停8项新增测试，加既有47项共55项通过；覆盖全怪种、新生怪、接触伤害暂停、移动恢复、30／60／120fps和跨帧余量、磁场不拉动。实机验证按钮、冷却、暂停和重新开局；素材制作记录见[预览](../../离线素材库/弹壳打工/制作记录/通用强化与时间停止/README.md)。
