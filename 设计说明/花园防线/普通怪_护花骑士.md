# 护花骑士

- 类型：普通怪；代码标识：`shielder`。
- 定位：护盾重甲怪物。
- 默认版记录：2026-10-13；数据来源：[游戏源代码](../../frontend/src/core-breach-legacy.html)。

## 角色与造型

粉蓝骑士方体、奶油叶盔、绿色叶盾与浅色腰甲。所有怪物采用有厚度的圆润小方体、深色竖眼和清晰表情，与植物守卫、草地和暖色石板路统一。

## 默认属性

本文记录当前代码的默认值。时间、移速和每秒输出均以游戏模拟时间计；主循环 `dt = 现实时间 × 倍速 × 0.5`，所以1x下1模拟秒约对应2现实秒。射程和速度按画布 `scaleRatio` 等比缩放。伤害、生命、费用、移速和参考范围默认向上取整；攻速、时间及倍率保留小数精度。百分比以整数向上显示，实际计算保留原比例。屏幕缩放与移动坐标允许小数。持续火焰累计小数余量后按整数扣血，避免逐帧取整改变输出。玩家自定义配置、邻格增伤、超频和怪物防御会改变实战值。

| 属性 | 默认值 |
| --- | --- |
| 生命倍率 | 1.85倍 |
| 防御减伤 | 25% |
| 承受普通伤害 | 75% |
| 配置移速 | 45 |
| 有效移速（scaleRatio=1） | 32 / 模拟秒 |
| 1x现实参考移速（scaleRatio=1） | 16 / 秒 |
| 配置半径 | 20 |
| 运行逻辑半径 | 18 × scaleRatio |
| 初始护盾 | 120 |
| 击败能量 | 28 |
| 击败积分 | 30 |
| 进入终点扣生命 | 1 |
| 类型 | 普通怪 |

普通怪物运行时统一使用18 × scaleRatio逻辑半径，配置中的原始radius列为设定数据；首领使用自身配置半径。素材的帽子、翅膀与武器不扩大命中判定。

## 生命计算与波次成长

构造器公式：`HP = ceil(关卡基础HP × 生命倍率 × 1.12^(波次-1) × hpScale)`。三张正式地图基础HP分别为100、110、121。正式波次队列又传入`hpScale = 1.14^(波次-1)`，因此普通正式生成叠乘两项波次成长；首领还有专属额外系数。

| 基准参考 | 花圃01 | 花圃02 | 花圃03 |
| --- | --- | --- | --- |
| 第1波、hpScale=1 | 185 | 204 | 224 |

参考行只用于比较类型，不代表本怪物一定在第1波出场。

## 能力与行为

出生时获得120点独立护盾，护盾先承受经过防御折减的伤害，超出的部分扣生命。当前不恢复护盾，也没有向附近怪物提供护盾的逻辑；shieldAura字段实际只用于启用自身初始护盾。EMP先将护盾置0，再造成280点无视防御的伤害。

伤害先按防御折减并向上取整，再消耗护盾，最后扣生命；持续火焰先累积各来源的小数余量，按累计结果整数扣血，EMP无视防御。到达终点按表扣花园生命。正式击败后积分立即增加，能量通过飞行金币结算。

## 动作与受击反馈

每种怪物有待机、左步行走、右步行走和受击四姿态；沿路线移动时保持直立，行走姿态随步频交替。实际生命受伤时受击姿态持续0.14模拟秒，护盾完全吸收伤害时不触发生命受伤姿态。静止、眩晕或系统减少动态效果下使用待机；隐身、护盾、霜晶、眩晕及血条由独立层绘制。

## 应对与测试建议

持续输出可破盾；EMP直接清除护盾。盾被完全吸收的种子/雪球命中仍显示接触效果，但不闪烁身体受伤层。

第0关可选择此怪物与任意单塔，生命由测试配置直接覆盖（默认300，范围1–1000000），可切换静止/移动并慢放。测试中怪物始终显形、关闭分裂、不发能量和积分；击败或到达终点后0.8模拟秒自动补一只，不扣花园生命。
