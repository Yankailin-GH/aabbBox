# 设备识别与全屏

更新时间：2026-10-14。适用于花园防线，包含独立游戏页面和工具首页的“守护花园”入口。

## 设备识别

两种入口与其他游戏共用 [game-display.js](../../frontend/src/arcade/game-display.js)。根据浏览器设备标识、系统标识和触摸能力判断，不使用窗口宽度或横竖屏作为电脑与移动设备的分类依据。

- 手机与 Android 平板使用移动设备规则。
- iPad 即使使用桌面版网站标识，也结合 Mac 标识与多点触摸能力按移动设备处理。
- Windows、macOS、Linux 与 ChromeOS 电脑使用电脑规则，Windows 触屏电脑仍归为电脑。
- 无明确系统标识时，多点或单点触摸且主指针粗、无悬停能力的设备使用移动设备规则，其余按电脑处理。

浏览器伪装或修改设备标识可能影响识别结果；窗口缩小不会使电脑切换为移动设备。

## 默认进入行为

- 电脑：从工具首页启动、开始正式关卡或进入第0关时，均不自动请求浏览器全屏、不自动开启 CSS 沉浸模式、不自动锁定竖屏。游戏仍按现有窗口尺寸适配。
- 手机和平板：工具首页点击“守护花园”时默认请求全屏；独立页面点击开始正式关卡或第0关时，默认开启 CSS 沉浸模式并请求浏览器全屏，尝试锁定竖屏。
- 原生全屏被浏览器限制或不支持时，保留页面内的游戏展示；微信页面沿用 CSS 沉浸模式。
- 页面打开或刷新仍先进入关卡选择，不自动恢复旧战局。浏览器原生全屏请求在上述点击操作中发起。

## 窗口布局

工具首页的游戏容器使用完整可用宽度。可用宽度达到 700px 时，外层游戏框与内部游戏区域的宽度上限统一为 1200px，选关卡片按可用宽度自动排列为多列；窄窗口保留单列选关与内部 540px 宽度上限。独立页面采用相同的宽窗口布局，布局断点不参与电脑与移动设备的身份判断。

战场继续按地图网格等比缩放并居中，宽窗口不会拉伸地图或改变范围、移速、伤害等游戏规则。电脑仍由用户手动控制全屏。

## 手动控制与安装入口

首页和设置中的全屏按钮继续支持电脑手动进入或退出全屏。从工具首页启动后，退出全屏会保留当前游戏，关闭游戏仍使用退出按钮。

[安装清单](../../frontend/src/legacy-manifest.json)使用 `standalone` 显示模式，不再优先声明 `fullscreen`；电脑安装后使用应用窗口。移动设备开始游戏时仍遵循默认全屏规则。

实现入口：[游戏页面](../../frontend/src/core-breach-legacy.html)、[工具组件](../../frontend/src/tools/core-breach-game/component.js)。
