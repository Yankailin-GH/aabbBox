## 数值口径

本文记录当前代码的默认值。时间、移速和每秒输出均以游戏模拟时间计；主循环 `dt = 现实时间 × 倍速 × 0.5`，所以1x下1模拟秒约对应2现实秒。射程和速度按画布 `scaleRatio` 等比缩放。伤害、生命、费用、移速和参考范围默认向上取整；攻速、时间及倍率保留小数精度。百分比以整数向上显示，实际计算保留原比例。屏幕缩放与移动坐标允许小数。持续火焰累计小数余量后按整数扣血，避免逐帧取整改变输出。玩家自定义配置、邻格增伤、超频和怪物防御会改变实战值。

怪物正式波次生命同时使用构造器1.12成长和队列1.14成长；闪避、首领干扰/跃迁为当前未执行的预留参数，相关文档已标明。
