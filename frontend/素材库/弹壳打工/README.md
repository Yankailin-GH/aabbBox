零域脉冲炮[当前规则](../../../设计说明/弹壳打工/零域脉冲炮.md#二战斗机制与循环流程)已调整为三条相同增量升级与天降极光：每级半径＋16、微核＋1、电浆每秒＋12%D，残域固定2.5秒。普通攻击沿用蓝焰核心、中心控制与微核小磁场；超武每10秒独立召下半径5细束，0.3秒落地，再用1秒扩成半径30的笔直蓝白光柱，两边黄色辉光，60%不透明度并结算600%D必暴，可再判定额外暴击；光柱1秒淡出，地面坍缩为普通聚能黑洞的1.5倍半径，3秒内每秒100%D、减速60%，不聚怪，不再发射超武核心。图集、蓝色黑洞PNG及元数据原样保留；当前图集使用主核心、微核、电浆三格，原坍缩弹体格为历史素材。天降扩柱、光柱淡出、落点提示、喷焰由Canvas绘制；地面坍缩使用新增的蓝紫电浆破坏地面PNG，保留碎裂石板、土层断面和下陷层次。最新截图与版本记录见[制作记录](../../../离线素材库/弹壳打工/制作记录/脉冲炮/README.md)。

## 通用强化与时间停止

- 当前使用`icons/upgrade-speed.svg`（青绿疾行靴）、`upgrade-damage.svg`（橙色能量爆闪）、`upgrade-crit.svg`（玫红切面晶核）、`upgrade-rate.svg`（紫色超频芯片）；四类通用升级卡使用独立素材，增量文字由界面显示。
- 主动技能使用`icons/skill-time-stop.svg`（冰蓝秒表与暂停符号），替换旧脉冲按钮；五枚图标均为项目原创手写SVG、128×128透明画布，无外部素材或生成图片，元数据见`icons/common-time-stop.json`。
- 对应说明：[总体玩法](../../../设计说明/弹壳打工/总体玩法.md)、[时间停止](../../../设计说明/弹壳打工/主动技能_时间停止.md)；[制作记录与预览](../../../离线素材库/弹壳打工/制作记录/通用强化与时间停止/README.md)。

### 范围与破坏坍缩素材

普通聚能黑洞、微型磁场与电浆按实际判定半径绘制并裁切，不叠加实线范围圆；普通黑洞同时移除外围虚线圆，聚能与爆后收缩的纹理转速为1.44rad/s（原来的30%），主爆仅使用短弧冲击波。超武半径5下降0.3秒，再用1秒扩成半径30蓝白直柱，黄色边光、不透明度80%，瞬间伤害同步半径30；地面持续伤害／减速半径仍为1.5R。

新增`effects/blaster-collapse-ruined-ground.png`及同名JSON，1254×1254透明PNG，基于用户蓝紫电浆图由内置imagegen编辑生成，加入碎裂石板、暴露土层、下陷断面与碎石，保留青蓝电裂隙；原图直接复制，四角透明，无棋盘背景。源矩形`(72,54,1113,1112)`，按地面直径2R绘制并裁切，运行时整体不透明度40%、不旋转地块；替换旧Canvas纯色圆盘、外圈和规则线裂缝。来源、完整提示词和[实机预览](../../../离线素材库/弹壳打工/制作记录/脉冲炮/README.md)保存在制作记录，原PNG及图集保持历史可追溯。
