## 维护约定

- 在用新素材放入所属游戏目录；未接入的设计稿先保存在离线库。文件名与代码类型标识保持稳定。
- 当前机制和动作设计说明保存在仓库根目录的 `设计说明/游戏名/`；素材来源、历史版本及用途在游戏素材索引中记录。
- 历史素材和制作记录位于 `离线素材库/游戏名/`，不代表当前生效能力；以游戏代码和设计说明为准。
- 调整目录时同步更新页面、绘制模块、生成工具、测试和文档链接。
- 本目录位于前端静态目录内，随 `frontend/` 一起预览和部署；游戏页面中的引用相对于页面或绘制脚本解析。
- 项目共用的标识及 favicon 保存在 [品牌素材目录](../src/assets/brand/README.md)。

## 自动整理

在项目根目录执行 `python3 scripts/manage_assets.py sync`；本地打包使用 `./pack.sh`。运行代码新引用的离线素材会恢复到原目录，移除引用的素材会自动归档；普通文档／制作预览引用不会导致素材进入发布包。动态引用须维护 `scripts/asset-rules.json`。迁移清单与哈希见[离线素材库](../../离线素材库/README.md)。
