# 技术美术规范

## 图像与坐标

- 母版：`1024x1024`、RGBA PNG、sRGB、透明背景。
- 动画帧：`512x512`、相同画布、相同 placement。
- 运行图集：`768x512`，`6x4` 网格，每格 `128x128`，不旋转、不裁边。
- 图标：`128x128`，用于约 `64 CSS px` 战场显示。
- 详情：`512x512`，用于约 `240 CSS px` 菜单展示。
- 坐标：左上原点，X 向右，Y 向下；锚点均使用 `0..1` 归一化值。
- 默认朝向：右侧为 `0deg`，屏幕坐标下正角度表现为顺时针。

## 锚点字段

- `placement`：塔与地图格的落地点；所有状态和等级不变。
- `aimPivot`：炮头或能量核心的瞄准旋转中心。
- `muzzle`：弹体或射线起点；太阳花为 `null`。
- `effectOrigin`：范围技能和程序化特效原点。

精确数值见 `metadata/towers/*.json`。接入时先按归一化坐标乘以实际绘制尺寸，再叠加塔的屏幕位置。

## 运行性能

- 每塔每级独立图集，可按关卡实际出现的塔型延迟加载。
- 单张运行图集 GPU 展开约 `1.5 MiB`；同时驻留五个三级图集约 `7.5 MiB`。
- Canvas 使用线性采样；不要使用 nearest-neighbor。
- atlas JSON 不使用旋转帧，减少原生 Canvas 播放器的解析分支。
- 避免逐帧创建新 `Image`、数组或临时对象；帧矩形和锚点应在加载时缓存。

## 验收清单

- PNG 具有真实 alpha，透明区没有不透明底色或棋盘格。
- 五塔各有三级；每级母版、四段帧、图集、图标、详情和 JSON 均存在。
- `idle` 首尾连贯；`attack` 第 2 帧与发射特效一致；placement 不漂移。
- 在 `32px`、`64px` 和 `240px` 三档人工检查轮廓与等级差异。
- Chrome 与 Safari 使用 `file://` 相对路径均能加载预览页。
- manifest 中的 SHA-256 与交付文件一致。
