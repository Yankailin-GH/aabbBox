# 离线素材库

这里保存未被游戏运行代码引用的历史素材、母版、逐帧图片、旧图集、概念图、制作提示词、实机预览和生成工具。按游戏名保留原来的子目录结构，**不参与前端打包或部署**。

游戏正在使用的素材及配套元数据仍在 [`frontend/素材库/`](../frontend/素材库/README.md)，现有页面 URL 保持稳定。项目品牌文件仍保存在 `frontend/src/assets/brand/`。

## 检查、恢复与打包

在项目根目录运行（Python 3.9+，无第三方依赖）：

```bash
python3 scripts/manage_assets.py audit
python3 scripts/manage_assets.py sync
./pack.sh
./pack.sh --output /绝对路径/frontend.tar.gz
```

- `audit` 仅读取，显示在用数量、离线数量与待迁移项。
- `sync` 扫描 `frontend/index.html`、`frontend/src/` 的 HTML／JS／CSS／SVG 静态引用，并结合 [`asset-rules.json`](../scripts/asset-rules.json) 中的动态拼接与关联元数据规则。文档、测试和离线预览中的引用不算运行引用。
- 未使用文件移到本库；运行代码重新引用 `../素材库/游戏名/原路径` 时，文件自动恢复至原在线位置，恢复原 URL。不要手动复制出两份同名文件。
- 打包前会自动同步两库，缺失引用、动态规则失效或同名冲突会阻止打包；`deploy.sh` 复用相同打包入口。
- 只压缩 `frontend/`，因此本库、`设计说明/`、`scripts/` 和 `打包文件/` 不会进入前端压缩包。不会联网或自动部署。
- 命令行大小统一显示为两位小数的MB（1 MB=1,000,000字节），例如 `archiveSize: "39.19 MB"`；清单中的原始字节数继续保留便于校验。`deploy.sh`通过现有scp逐文件打印上传百分比，只有成功退出才显示100%。

新增动态路径时，维护 `scripts/asset-rules.json`：声明加载模块、用于核对的代码片段、必要素材路径或限定通配符。花园防线当前 icons／detail 回退资源仍在线，未调用的 atlas、母版和帧序列离线；不要只靠文件名搜索判断使用情况。

## 目录与追溯

- [花园防线](花园防线/README.md)：历史 SVG／母版、逐帧动画、旧版图集与制作工具。
- [弹壳打工](弹壳打工/README.md)：武器历史稿、角色概念图、提示词与实机预览。
- [西游星球](西游星球/README.md)：历史普攻帧、旧棒影与图集。
- [`素材清单.json`](素材清单.json)：每个文件的在线／离线位置、大小、SHA-256 和实际引用来源。
- [`迁移记录.json`](迁移记录.json)：每轮迁移的原路径、新路径与时间。
- [`校验结果.json`](校验结果.json)：本轮包体大小、图片完整性、测试及解压后浏览器验证记录。

素材原图按文件移动，不重新压缩、不删除历史稿；文档链接、生成工具和测试需随路径更新。本库仍属于项目源文件，应随仓库备份。
