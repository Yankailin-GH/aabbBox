## 局内动作重设计

- 日期：2026-10-14。用户要求重新设计人物手持武器和发起攻击的动作。
- 实现：Canvas 绘制独立的肩、肘、腕与圆环握持点，复用现有黑色飞刃 PNG。没有生成或替换新的角色图片。
- 待机：单手扣环，飞刃在朝向侧腰部，另一只手放松；上下索敌时保持腰侧握持。
- 投掷：收臂蓄势 → 甩腕出刃 → 空手收势 → 下一把飞刃渐显补刃 → 腰侧持刃。默认动作200ms，84ms时真正发射并播放音效；高攻速按发射间隔压缩动作。
- 角色层级：巡游者以动态手臂替代静态手臂；小韩的原 PNG 在局内按手臂区域裁切，青袍袖口和手指由 Canvas 绘制。向上投掷时将手臂放在身体后面，避免盖住脸。
- `动作分镜预览.png`：两个角色的五阶段放大预览，由当前游戏 Canvas 直接导出。
- `朝向分镜预览.png`：两个角色在右、左、上、下四个方向的阶段预览。
- `战场动作预览.png`：浏览器实际战场截图；测试敌人与测试血量只存在于预览浏览器内存中。
