# 通用强化与时间停止 · 制作记录

- 日期：2026-10-15；来源：项目原创手写SVG，不使用外部图片或AI生成图片。保持粗深色描边、大色块与有限亮面，四类属性使用不同颜色和轮廓，保证卡片40px、按钮48px可辨认。
- 当前素材：`../../../../frontend/素材库/弹壳打工/icons/upgrade-speed.svg`（疾行靴）、`upgrade-damage.svg`（能量爆闪）、`upgrade-crit.svg`（切面晶核）、`upgrade-rate.svg`（超频芯片）、`skill-time-stop.svg`（秒表＋暂停）。全部128×128、viewBox 64×64、透明背景，名称和百分比不烘焙进图标；`../../../../frontend/素材库/弹壳打工/icons/common-time-stop.json`记录来源及哈希。
- 消费位置：`frontend/src/core-breach-game.html`普通升级卡、右下主动技能按钮。时停蓝色覆盖层、怪物圆环与暂停标记由Canvas实时绘制。
- 当前数值：移速＋18%、伤害＋30%、暴击率＋10%且暴伤＋25%、实际攻速＋16%；时间停止为全地图静止2秒、冷却60秒。暴击增益按百分点增加，初始暴伤200%→225%；达到上限时显示真实增量。
- 预览：[五枚图标](通用强化与时间停止图标预览.png)、[普通卡片](通用百分比升级卡手机预览.png)、[时停生效手机](时间停止生效手机预览.png)、[桌面](时间停止桌面预览.png)。测试状态仅存在浏览器内存，不写入默认游戏配置。
- 验证：55项测试通过；实机点击四种通用卡，确认百分比与图标加载，核对全武器暴伤、全怪种静止与新生怪继承、玩家攻击继续、2秒恢复、60秒冷却、暂停冻结、重开清理及320／390／1280px布局。
- 规则以[总体玩法](../../../../设计说明/弹壳打工/总体玩法.md)和[时间停止](../../../../设计说明/弹壳打工/主动技能_时间停止.md)为准。
